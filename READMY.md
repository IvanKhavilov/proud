# 🏗 Proud Project — Landing Page

## О проекте

Проект реализует одностраничный сайт с:

- полноэкранным бургер-меню
- кастомной валидацией формы
- анимациями при скролле
- слайдерами портфолио (Swiper)
- адаптивной версткой

Основной акцент сделан на:

- UX (поведение меню, блокировка скролла)
- производительность
- чистую структуру кода

---

## Технологии

- HTML5
- CSS3 (BEM, переменные, адаптив)
- JavaScript (Vanilla JS)
- Swiper.js
- Intersection Observer API

---

## Основной функционал

### Бургер-меню

- fullscreen overlay
- блокировка скролла (`lock-scroll`)
- закрытие по:
  - клику на ссылку
  - Escape
- компенсация scrollbar (fallback для старых браузеров)

---

### Слайдеры

- главный слайдер (fade эффект)
- вложенные слайдеры с превью
- синхронизация thumbs + main

---

### Scroll-анимации

- через `IntersectionObserver`
- отключаются при открытом меню
- поддержка prefers-reduced-motion

---

### Форма

- маска телефона (+38 формат)
- валидация
- имитация отправки
- success modal
